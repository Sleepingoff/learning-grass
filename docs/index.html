개인정보처리방침

Learning Grass는 온라인 강의 학습 시간을 기록하고 잔디 형태로 시각화하는 Chrome 확장 프로그램입니다. 이 문서는 확장 프로그램이 접근하는 정보와 그 사용 목적을 설명합니다.

시행일: 2026년 10월 16일 · 최종 수정일: 2026년 10월 16일

핵심 안내
Learning Grass는 강의 시청 기록과 설정을 사용자의 브라우저 로컬 저장소에 저장하며, 외부 계정이나 별도 서버 없이 작동합니다.

1. 처리하는 정보

학습 시간 기록 기능을 위해 다음 정보가 처리될 수 있습니다.

  • 강의 사이트의 도메인, 강의 페이지 주소(URL) 및 페이지 제목
  • 과목명 또는 강의명, 사용자가 직접 입력한 과목명
  • 영상 재생 상태, 시청 시작·종료 시각 및 실제 시청 시간
  • 사용자가 추가한 강의 사이트 및 표시 설정

강의 페이지 주소나 제목에 개인정보가 포함되어 있을 수 있으므로, 해당 정보도 신중하게 취급합니다.

2. 정보 이용 목적

수집한 정보는 강의 시청 시간 측정, 날짜별 학습 잔디 생성, 강의별 타임라인 표시, 학습 통계 제공 및 사용자 설정 유지에 사용됩니다.

3. 브라우저 권한

  • storage: 학습 기록과 사용자 설정 저장
  • tabs: 강의 탭과 별도로 열린 학습 창 식별
  • alarms: 학습 세션 관련 주기적 작업
  • scripting: 지원되는 강의 페이지에서 재생 상태와 강의 정보 감지
  • sidePanel: 브라우저 오른쪽에 학습 대시보드 표시
  • 호스트 접근 권한: 지원 사이트 및 사용자가 등록한 사이트의 강의 정보 확인

이 권한들은 강의 기록, 사이드 패널 표시 및 사용자가 선택한 사이트 지원을 위해 선언되어 있습니다.

4. 저장 및 보유

학습 기록과 설정은 Chrome 확장 프로그램의 로컬 저장소(chrome.storage.local)에 보관됩니다. 저장 데이터는 브라우저 프로필 또는 확장 프로그램 삭제 등의 작업으로 사라질 수 있습니다.

별도 보유 기간을 두지 않고 사용자가 기록을 삭제하거나 확장 프로그램 데이터를 제거할 때까지 보유하는 것을 기본으로 합니다.

5. 외부 전송 및 제3자 제공

현재 배포하는 Learning Grass v0.1.12 코드에는 학습 기록을 개발자의 외부 서버로 업로드하거나 제3자에게 전송하는 기능이 없습니다.

6. 사용자의 선택권과 데이터 삭제

사용자는 Learning Grass 대시보드에서 학습 기록 전체 삭제를 실행하거나, Chrome의 확장 프로그램 관리 화면에서 Learning Grass를 삭제하여 로컬 확장 데이터를 제거할 수 있습니다. 기록 내보내기(JSON) 기능도 제공합니다.

데이터 삭제 전에는 필요한 기록을 별도로 백업하는 것을 권장합니다. 브라우저 환경에 따라 삭제 동작이 달라질 수 있습니다.

7. 정보 보호

학습 정보 접근을 기능 제공에 필요한 범위로 제한하고, 브라우저가 제공하는 확장 프로그램 저장 및 권한 체계를 사용합니다. 사용자의 브라우저 또는 기기 보안 상태에 따라 위험이 발생할 수 있습니다.

8. 개인정보처리방침 변경

서비스 기능이나 데이터 처리 방식이 변경되는 경우 본 페이지의 내용과 수정일을 갱신합니다. 중요한 변경 사항은 적절한 방법으로 안내합니다.
