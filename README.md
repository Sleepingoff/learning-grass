# Learning Grass 🌱

Chrome 사이드 패널에서 온라인 강의 시청 시간을 기록하고 GitHub 스타일 학습 잔디로 보여주는 확장 프로그램입니다.

## 주요 기능

- 방통대, 인프런, Udemy 강의 재생 시간 감지
- 사용자 정의 강의 사이트 등록
- 최근 1주 / 1개월 / 1년 학습 잔디
- 타임라인, 강의별 필터 및 학습 통계
- 방통대 과목명 수동 입력
- JSON 기록 내보내기와 기록 삭제
- 브라우저 로컬 저장소 기반 기록

## 설치

1. 이 저장소를 ZIP으로 다운로드하거나 클론합니다.
2. Chrome의 `chrome://extensions`로 이동합니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. **`extension` 폴더**를 선택합니다.
5. 확장 아이콘을 클릭하면 오른쪽 사이드 패널이 열립니다.

현재 버전: **v0.1.12**. 교육 플랫폼별 플레이어 구조에 따라 자동 감지가 제한될 수 있습니다.
